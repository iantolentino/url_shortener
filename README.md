# URL Shortener

A full-featured URL shortener built with Python Flask, featuring analytics, custom aliases, and REST API.

## Features

- **URL Shortening**: Convert long URLs to short, shareable links
- **Custom Aliases**: Create memorable custom short codes
- **Analytics**: Track clicks, referrers, and geographic data
- **REST API**: Programmatic access to all features
- **Responsive Design**: Works on desktop and mobile devices
- **Dashboard**: Manage and view all shortened URLs

## Tech Stack

- **Backend**: Python, Flask, SQLAlchemy
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5
- **Database**: SQLite (production: PostgreSQL)
- **Deployment**: Ready for Railway, Render, Heroku
